# بسته اصلاحات آزمایشی PRS

این بسته فقط کد است؛ هیچ اطلاعات کاربر یا دیتابیس در آن وجود ندارد.

## تغییرات
- آزمون‌های سایت و آزمون قدیمی ربات: یک تلاش برای هر دوره، حتی اگر مأموریت قبلاً با سقف ۲ ساخته شده باشد.
- کنترل عضویت کانال در هر درخواست احراز هویت‌شده سایت (به جز حساب مدیر).
- شرط ۳ دعوت معتبر و کیف پول BNB معتبر برای شروع و دریافت پاداش ماین.
- حفظ کیبورد دائمی ربات هنگام ارسال لینک ورود.
- کارت‌های سایت رسمی، X و اینستاگرام.

## استقرار ایمن
1. فقط در branch آزمایشی prs-web-portal ادغام کنید.
2. Mongo آزمایشی و متغیرهای Railway را بررسی کنید؛ به پایگاه داده اصلی وصل نشوید.
3. با یک کاربر بدون دعوت، یک کاربر ۳ دعوتی بدون کیف پول، کاربر کامل، و کاربری که از کانال خارج شده آزمایش کنید.
4. آزمون با پاسخ غلط را در سایت و ربات انجام دهید؛ تلاش دوم باید رد شود.
5. برای جلوگیری از قفل‌شدن کاربران، bot باید در کانال دسترسی getChatMember داشته باشد.

**توجه:** این بسته به Railway یا GitHub منتشر نشده و تست یکپارچه با تلگرام و Mongo زنده انجام نشده است.

## اصلاحات تکمیلی نسخه ۲
- پیام‌های لینک ورود به پنل دیگر با `protect_content=True` ارسال نمی‌شوند؛ بنابراین محدودیت اسکرین‌شاتِ ناشی از این تنظیم برداشته شد. تنظیم مستقل «Restrict Saving Content» در گروه یا کانال تلگرام باید جداگانه بررسی شود.
- گزینه «شبکه‌های اجتماعی» بلافاصله بعد از «حساب من» به ناوبری سایت اضافه شد؛ شامل کارت‌های سایت رسمی، X و اینستاگرام.
- منوی کیبورد پایین ربات برای کاربران عادی فقط «پنل ایردراپ» را نشان می‌دهد؛ دستورات قدیمی و ابزارهای مدیر حذف نشده‌اند.
- آیدی عددی تلگرام از شناسه حسابِ پاسخ `/api/session` در «حساب من» نمایش داده می‌شود و دکمه کپی دارد.
- برای رفع منوی قدیمی ذخیره‌شده در تلگرام، پس از استقرار باید ربات یک پیام جدید با کیبورد تازه به کاربر ارسال کند (مثلاً پس از `/start`).
