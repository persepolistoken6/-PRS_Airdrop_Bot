# PRS Portal Fix v3 — تست قبل از انتشار

بر پایه بسته آزمایشی v2 ساخته شده است. فایل‌های __pycache__ حذف شده‌اند.

## تغییرات
- پاداش شخصی و همگانی ثبت‌شده از مسیر مدیریتی تلگرام (BOT_PORTAL_ONLY) پس از ثبت موفق، پیام تلگرام به دریافت‌کنندگان می‌فرستد. ارسال best-effort است؛ بلاک بودن ربات یا خطای شبکه مانع ثبت پاداش نیست. برای تعداد زیاد کاربران، صف پایدار و محدودسازی نرخ در استقرار اصلی توصیه می‌شود.
- در سایت، پاداش‌های مدیریت در «حساب من» قابل مشاهده‌اند و هنگام تازه‌سازی پنل، پاداش جدید نسبت به آخرین بازدید اعلان می‌شود. اعلان مرورگرِ بسته / push پیاده نشده است.
- پس از دریافت پاداش روزانه، تیک «دریافت شد» تا پایان ۲۴ ساعت در کارت پاداش نمایش داده می‌شود؛ تاریخچه فعالیت قبلی حفظ می‌شود.
- در مدیریت سایت، کلید فعال/غیرفعال کردن درخواست برداشت اضافه شده؛ API نیز درخواست‌های جدید را در حالت غیرفعال رد می‌کند. درخواست‌های موجود قابل بررسی باقی می‌مانند. مقدار پیش‌فرض فعال است.

## محدودیت‌ها
- اعلان‌های پاداش مسیر قدیمی خارج از BOT_PORTAL_ONLY و اعطای پاداش از پنل مدیریت سایت هنوز نیازمند یکپارچه‌سازی جداگانه هستند؛ این بسته آن مسیرها را پوشش نمی‌دهد.
- فقط بررسی نحوی Python و JavaScript انجام شده، تست با MongoDB و Telegram واقعی انجام نشده است.
- هیچ migration مخرب یا حذف اطلاعاتی اضافه نشده است.

## نصب
فایل‌ها را در همان مسیر قبلی GitHub جایگزین کنید؛ ابتدا روی Railway آزمایشی با MongoDB آزمایشی تست کنید. توکن ربات را هم‌زمان در دو poller فعال نکنید. پس از بکاپ کامل، انتقال به ربات اصلی انجام شود.
