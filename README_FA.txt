اصلاحات پنل مدیریت PRS

فایل‌های این بسته را در شاخه prs-web-portal جایگزین کنید:
- portal_features.py را به portal/features.py تغییر نام دهید و جایگزین کنید.
- web.py را جایگزین کنید.
- app.js را در پوشه static جایگزین کنید.

تغییرها:
- نمایش کیف پول، شبکه‌های اجتماعی، تعداد دعوت، پاداش کسب‌شده، پرداخت‌شده و مانده در نتایج جست‌وجو.
- جزئیات گسترده‌تر حساب: ثبت‌نام، پاداش‌ها، مأموریت‌ها، ماین، پرداخت‌ها و سابقه.
- افزودن زبانه واجدین شرایط: حداقل ۳ دعوت تأییدشده، کیف پول معتبر BNB، مانده قابل برداشت حداقل ۲۰٬۰۰۰ PRS و حساب فعال.

پس از جایگزینی فایل‌ها، Railway با اتصال خودکار GitHub دوباره deploy می‌کند. قبل از آن متغیر BOT_TOKEN را هم بررسی کنید؛ خطای قبلی 401 از توکن تلگرام بود.
