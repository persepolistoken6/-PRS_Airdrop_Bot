# اعلان‌های PRS — نسخه آزمایشی

- زنگوله در هدر و نقطه قرمز برای اعلان‌های خوانده‌نشده.
- اعلان‌های پاداش مدیر از تاریخچه، پاسخ پشتیبانی از تیکت‌ها و پیام مدیریت از announcement خوانده می‌شوند.
- نمایش کارت جداگانه پاداش مدیر، متن اعلان مدیریت در داشبورد و پاسخ پشتیبانی در حساب کاربر حذف شده؛ ارسال تیکت و سوابق مالی حفظ شده‌اند.
- اعلان‌ها در صندوق پیام‌ها نمایش داده می‌شوند؛ «خواندم» و «علامت‌گذاری همه» موجود است.
- وضعیت خوانده‌شده فعلاً در localStorage مرورگر برای هر شناسه کاربر ذخیره می‌شود، نه MongoDB؛ بین Chrome و مرورگر تلگرام همگام نمی‌شود.
- این نسخه اعلان پوش مرورگر بسته نیست و فقط رویدادهای موجود در API را نمایش می‌دهد.
- قبل از استقرار روی دیتابیس آزمایشی تست شود.
